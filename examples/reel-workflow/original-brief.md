## Production instructions

The [stage guide](production-guide.mdx) is the working reference for the JavaScript animation modules. It specifies deterministic frames, word-timed effects, camera motion, captions and the mascot’s actions. The guide is reproduced unchanged from the recovered production directory. It can include later revisions; its file references require that project and are not a standalone download.

The opening prompt also cited [mexicat/pdoom-video](https://github.com/mexicat/pdoom-video) and [JohnHeibel/PDoomVideo](https://github.com/JohnHeibel/PDoomVideo) as visual references. The production guide names ClaudeAnimationBase as another reference. No third-party code, footage or music is included here.

The project combined public MCP discovery with internal transcript access and human selection. The [workflow note](README.md) explains those boundaries and provides a separate research starter. The excerpts above are the original creative direction; that starter was written afterward.
