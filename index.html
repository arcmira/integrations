YouTube transcript search in practice.

Use Arcmira MCP to find spoken passages across indexed YouTube and podcast transcripts. Open a timestamp to hear the original recording, or use the passage in a video.

01

Play a quote timeline

Hear five conversations about vibe coding. Each excerpt opens the original recording near the selected sentence. You can explore the saved results without an API key.

Get the Python worksheet and sample CSV or open it in Google Colab to export the passages and timestamps as a CSV.

Make video quote cards with Remotion

Watch an 18-second example, then render it yourself from saved passages. The example includes the source links and timestamps for each card.

03

Add transcript search to an AI SDK agent

Install the TypeScript adapter and give your agent tools to search YouTube and podcast transcripts and look up people by name.

04

Export a transcript as WebVTT

Turn a saved transcript into a caption file for your video or podcast. The local Python example keeps each cue’s timing and any speaker labels in the response.

05

Install the YouTube transcript search SDK

For TypeScript or JavaScript, run npm install arcmira. The npm package includes the SDK and CLI. Run npx arcmira search --help to see the transcript search options.

For Python, run python -m pip install arcmira in your virtual environment. The PyPI package includes synchronous and asynchronous clients. The SDK guide shows how to authenticate and run a search.
