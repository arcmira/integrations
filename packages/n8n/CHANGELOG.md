# Changelog

## 0.2.0 candidate

Adds the Arcmira Trigger, a polling trigger that emits each newly delivered alert from a chosen monitor through GET /v1/monitors/{id}/alerts. Alerts held back, skipped or failed never fire it. Its monitor picker marks paused and digest-only monitors, which never fire it. The Arcmira node, the package description and the README lead use the new descriptions.
