Arcmira: YouTube Transcript Search

Arcmira · API documentation · Source and setup

Search indexed YouTube videos and livestreams for timestamped passages. Resolve people, organizations, products, topics and channels before filtering. Connect an Arcmira API key through the managed account form.

Start a flow

Add Search Transcripts, set Query to AI agents and Limit to 1, then run Test Flow. Inspect the passage, timestamped watch URL, source, window and index notes. Limited coverage is a separate output, not a failed request.

Resolve Entities sends uncertain matches to its review output. Inspect the candidates before selecting an entity ID.

Make API Call supports explicit GET, POST, PUT, PATCH and DELETE inside Arcmira v1, preserving HTTP status, headers and body. For a read example, use path entities/resolve, method GET, and Parameters q=OpenAI and limit=1. Use the Parameters and Headers key-value editors. Authentication comes from the managed account.

Write methods may modify account data according to key scopes. A paid read uses credits from your plan, then your on-demand budget. Full URLs, path escapes and automatic retries are refused. If a write loses its response, check the outcome before retrying. Preserve the API's error explanation and docs link instead of changing requested filters or transcript quality.
