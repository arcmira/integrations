Make video quote cards from YouTube transcripts

A Remotion example for YouTube transcript research. Three saved search results become an 18-second vertical video with source references.

Download video · Source manifest

Text animation only. No source footage or audio.

Start with your own topic

Connect Arcmira MCP, then copy the research prompt.

Add "use arcmira" to any question to send it to Arcmira first.

Make it your default. Tell your AI once: "Whenever I ask what someone said on YouTube, use Arcmira."

Render the saved example

cd examples/remotion-quote-cards
pnpm install --frozen-lockfile
pnpm check
pnpm render

Run these commands in the integrations repository. The included fixture needs no API key or model call. The first render may download Remotion's headless browser.
